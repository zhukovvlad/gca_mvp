**Когда читать:** трогаешь разбор XLSX и openpyxl: объединённые ячейки, форматы чисел, шапки групп, NLP-нормализацию наименований.

- Парсер опирается на объединённые ячейки (`build_merged_shape_map`); не ломать досрочный выход по merged-ячейке в первой колонке (признак конца позиций / начала summary).
- `normalize_job_title_with_lemmatization` тянет NLP-зависимости (pymorphy3/natasha) — оставить только реально используемые; spaCy-модель не тащить, если не используется. Нормализация должна быть **детерминированной** (одна строка → всегда один результат) — иначе разъедутся кэш, каталог и матчер.
- **Точность денег в xlsx ограничена форматом, а не кодом.** Формат хранит числа как IEEE-754 double: до ~15 значащих цифр значение доезжает точно, дальше теряет младшие разряды (замер: `12345678901234567.89` → `1.234567890123457e+16`). Писать деньги текстом нельзя — банк складывает колонку, а `СУММ` по тексту даёт ноль. То есть §3 выполняется до файла включительно по величинам договоров ГП, но «полная точность» в xlsx — неправда, и обещать её не надо.
- **`Worksheet.cell(row=, column=, value=None)` в openpyxl НИЧЕГО НЕ ПИШЕТ.**
  Тело метода — `if value is not None: cell.value = value`, поэтому очистить
  ячейку так нельзя; нужно `ws.cell(row=, column=).value = None`. Замерено на
  фиче «колонки по заголовкам»: два теста «очищали» ярус шапки первым способом,
  ярус оставался заполненным, и обе проверки были бы зелёными по совершенно
  другой причине, чем написано в их докстроках. Тест, который что-то «стирает»
  этим вызовом, не проверяет того, о чём говорит.
- **Чтение НЕ-якорной ячейки объединённого диапазона даёт `None`.** Значение
  живёт только в верхней левой ячейке; `ws.cell(...)` по любой другой отдаёт
  пустоту, и код молча теряет заголовок вместо того, чтобы упасть. Замерено на фиче
  «колонки по заголовкам»: смещение групповой шапки считалось как позиция колонки «Материалы», что
  совпадает с якорем лишь пока «Материалы» физически первая в группе. При
  перестановке подколонок внутри группы деньги раскладывались верно, а ставка
  НДС становилась `None` — дефект, которого не видел ни один тест, потому что
  все фикстуры переставляли группы целиком. Любое смещение, по которому потом
  ЧИТАЮТ объединённую шапку, обязано быть смещением якоря (`min_col`
  диапазона), а не позицией «удобной» колонки внутри него.
