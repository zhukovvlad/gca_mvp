## 4. Оракулы, а не рассуждения

**Три разовых сверщика** (`$SCRATCH`, в репозиторий не кладутся — после мержа
у них нет предмета). Контракт: код 0 только при полном совпадении, ненулевой —
при пустом извлечении, пропаже, перемещении и любом различии; при любом исходе
печатаются обе величины.

| Сверщик | Результат |
|---|---|
| `verify_move.py section-2` | 5 единиц против 5, sha256 `3f19945e…` с обеих сторон, отсутствующих 0, лишних 0, порядок сохранён, код 0 |
| `verify_move.py revision-6-18` | 29 против 29, sha256 `942258f1…`, отсутствующих 0, лишних 0, код 0 |
| `verify_sections_3_8.py` | 321 строка, sha256 `de76434616d5c71f4c83a3014e075d7e417bd789e7f1e8b697c066d3af15e41b` — совпало и с базой, и с зашитым эталоном, код 0 |

**Сверщик проверен снятием защиты, а не только на успехе.** Удаление строки
про `parser_tender_xlsx` из файла источников даёт код 1 и называет пропавшую
единицу. Без этой проверки «совпадение полное» означало бы «смотреть было
нечем».

**Канонизация расширена дважды по факту, и оба раза это названо в скрипте.**
Спека §2.8 требовала снимать относительные ссылки. Пришлось снимать ещё:

1. **квалификацию §-адресов** — при переезде в другой документ «§8» ОБЯЗАНА
   стать «`AGENTS.md` §8», иначе по правилу §2.1.1 она адресует сам файл;
2. **префикс цитаты** `> ` — в преамбуле врезка blockquote, в архиве тот же
   текст стоит абзацем.

Первое расширение вскрыло дыру, которую закрыл страж: канонизация снимает
квалификацию СИММЕТРИЧНО, поэтому доказать, что обязательная правка сделана,
сверщик не может — квалифицированный и неквалифицированный текст дают один
хэш. Это нашло ревью Task 2, и потому проверка 12 теперь ловит краткий `§N` в
файле источников. Первый же её прогон нашёл такую строку в самом файле.

## 10. Круги ревью: тридцать находок, из них семнадцать в моих же фиксах

попадать не должен, иначе критерий «ровно спека и план» ломается тогда, когда

плюс, потому что её снятие живёт внутри §9.2, которое в сумме выросло.

Остальные восемь: «19 находок» против 20; «пятое правило» против четырёх;
«21 упоминание фаз» без указания единицы счёта (это строки, не вхождения);
указатель §10 → §9.2 повис, потому что DoD фазы из §9.2 ушёл вместе со строкой
класса; оракул DoD 5 возвращал 19 строк вместо 15 — свои же документы фичи
добавили упоминания; прогноз фичи 3 сложен с двойным счётом врезок §7;
обязательство «разброс по годам» осталось без действующего носителя;
`check_12` требовал квалификации строже, чем правило §9.2, и это не было
названо.

**Урок, который стоит записи.** Ревью на собственные фиксы — не формальность:
из тридцати находок **семнадцать** жили именно в правках, сделанных по
предыдущему кругу. Дороже всего оказалась правка в постоянном корпусе: там
цена ошибки не «ещё круг», а неверное правило в памяти проекта.
