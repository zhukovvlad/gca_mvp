## Что сделано

1. **`just ci`** (`21449b9`) — рецепт `ci` плюс `ci-lock-backend`, собран из
   существующих рецептов. Состав сверен с двумя GitHub workflow командой, а не
   по памяти; шаги установки (`uv sync`, `npm ci`) в него не входят — их делает
   `just install`. В README добавлена строка в раздел «Тесты и линт».
2. **`AGENTS.md` v6.5** (`f9cccbf`) — §9 переписан на 9.1 цикл фичи / 9.2
   таксономия документов / 9.3 ветвление и PR / 9.4 фазы как вехи; преамбула
   больше не называет документ единственным источником истины по проекту; §10
   разделяет DoD проекта, фазы и фичи.
3. **Рамка фазы 7** (`a148ffd`) — `docs/phase7-frame.md`, 74 строки; черновики
   `phase7-brief.md` и `phase7-start.md` помечены врезками.

## Замеры

**`just ci`, зелёный путь:** 927 passed / 6 skipped backend — **267 с (4:27)**;
eslint и tsc чистые; vitest 18 файлов / 175 тестов — **52,7 с**. Полный прогон
около 5,5 минут. Это цена, которую платит фича, тронувшая код; правки только в
`docs/` от `just ci` освобождены (§9.3) — иначе процесс сам себя бы задушил.

**Негативная проверка (правило трёх слоёв, `AGENTS.md` §11):** временный
`import os` в конце `backend/utils.py` → `just ci` падает на шаге `lint-backend`
(ruff: `E402` + `F401`), `error: recipe lint-backend failed on line 156 with exit
code 1`, **последующие шаги не запускаются** — прогон вернулся за секунды вместо
четырёх минут, то есть pytest до дела не дошёл. Без этой проверки рецепт мог бы
оказаться зелёным всегда и быть бесполезным как гейт. Поломка снята
(`git checkout -- backend/utils.py`), дерево чистое.

**Инвариант истории фаз:** `grep -c "Статус: выполнено" AGENTS.md` = 2 до и
после правки §9 — список фаз 0–6 перенесён дословно, ничего не потеряно.

**Согласованность формулировок:** «единственный источник истины по проекту» в
актуальных документах не осталось; пять упоминаний остались в исторических
`phaseN-start.md`, которые по правилу не переписываются.

**Коллизия нумерации (найдена проверкой ссылок).** В старом §9 фазы были
нумерованным списком, и `docs/phase4-start.md` ссылается на «§9.4», имея в виду
**фазу 4**. Теперь §9.4 — подраздел «Фазы (вехи приёмки)». Документ
исторический и не переписывается, но при чтении старых брифингов «§9.N» надо
понимать как «фаза N», а не как подраздел. В актуальных документах все ссылки
`§9.1`–`§9.4` означают подразделы и разрешаются верно (проверено grep-ом).

  строчки, пока не закончит. Вывод на будущее: длинные прогоны запускать в фоне,
  а не прятать вывод в `tail`.
