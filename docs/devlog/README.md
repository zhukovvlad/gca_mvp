# Девлог

Журнал выполнения задач по проекту (трекер цен на материалы из PDF-накладных
УПД). Хронология работ — фиксируем что сделано, решения и их причины, подводные
камни, чтобы контекст не терялся между сессиями.

Каждый отчёт — отдельный файл вида `YYYY-MM-DD-<краткое-название>.md`.
Структура отчёта: что сделано, верификация, решения и нюансы, что осталось.
Запись добавляется по завершении задачи (обычно перед PR / после мержа в `main`).

Смежное:
- `docs/done/` — завершённые планы реализации (не хронология, а артефакты задач).
- `docs/superpowers/` — спеки и планы фич (`specs/`, `plans/`).
- `docs/TECH_DEBT.md` — зафиксированный технический долг.
