# `AGENTS.md`: указатель §12 и преамбула — сжать без потери фактов

**Гейт 1 пройден 03.09.2026** в диалоге. Спека **тонкая** по §9.1: направление
зафиксировано на гейте 1, здесь источник и дельта.

**Класс правки:** документация с проверочным инструментарием (§9.1) — вводится
один read-only скрипт, стерегущий DoD. Плана нет по тому же исключению;
`just ci` обязателен.

**Ревизия:** заводится **v6.17**. Правится не только форма: §12 получает
правило формата указателя, §9.2 — новый класс документа
`docs/AGENTS-revisions.md`, а DoD — обязательную проверку. Это правка процесса,
и по правилу, введённому v6.16, она обязана быть видна в истории источника
истины. Первая редакция этой спеки от ревизии отказывалась — неверно.

## 0. Метрика размера, чтобы её нельзя было прочитать двояко

**Символы после нормализации переводов строк к LF.** У этого файла их 128 052.
Байтов на диске 211 623, и оба числа верны каждое по своему определению:
кириллица в UTF-8 занимает два байта, а рабочее дерево держит CRLF, поэтому
`211 623 = 210 409 + 1 214 строк`. `wc -c` для порога в символах не годится.

```bash
python -c "import pathlib;print(len(pathlib.Path('AGENTS.md').read_text(encoding='utf-8')))"
```

## 1. Проблема с замерами

`AGENTS.md` — **1 214 строк, 128 052 символа, ~42 700 токенов**, и `CLAUDE.md`
предписывает читать его в начале каждой сессии. Ядро, нужное в любой сессии
(§1–3, §8, §9, §10), — около 7 600 токенов, то есть **18 % файла**.

| Что | Символов | Токенов |
|---|---|---|
| Указатель §12 | 18 236 | ~6 080 |
| Преамбула (16 врезок ревизий) | 19 232 | ~6 410 |

### 1.1. Указатель §12 противоречит собственной вводной

§12 объявляет разделение труда прямо: «в **файле** указано, чем именно
выстрадано и чего правило не ловит». Строка указателя обязана отправлять к
файлу, а не заменять его. Сейчас 16 строк весят 6–37 % своих файлов и
пересказывают их; самая длинная — **3 401 символ**. Это дублирование, которое
§9.2 запрещает («факт живёт в одном месте»).

**Проверено механически:** сверка чисел и идентификаторов в бэктиках из каждой
строки указателя против текста связанного инсайта дала три расхождения на 16
строк, из них **одно настоящее** — строка про `verifying-guards` сообщает
«четырнадцатый слой заведён внешним ревью **PR #34**», и этой атрибуции в самом
инсайте нет. Два других — переформулировки (`exit 0` против `exit code 0`,
`just ci | tail` против `tail -40`).

### 1.2. Преамбула: две мои гипотезы оказались неверны

**Первая: «мёртвая история, которую не читают».** Замер против: на конкретные
ревизии **66 ссылок** в `docs/`, и шесть номеров цитируются внутри самого
`AGENTS.md` вне преамбулы (`v6.7` — 14 раз, `v6.10` — 10, `v6.5` — 9). Выносить
преамбулу целиком значит лишить эти ссылки локальности.

**Вторая: «инвариант правят четыре ревизии из шестнадцати».** Тоже неверно, и
ошибка того же класса, что разбирал инсайт
[`count-answers-the-command-not-the-question`](../../insights/count-answers-the-command-not-the-question.md):
я искал в тексте врезок маркеры `ПРАВИТ ИНВАРИАНТ` / `ДОБАВЛЕН` — то есть считал
ФОРМУЛИРОВКУ, а не предмет. v6.7 говорит «одна осознанная ревизия… сужено до
своей области» и добавляет право `admin` в §3; регулярное выражение её не
увидело.

**Хуже: врезки классифицируют себя непоследовательно.** v6.6 добавляет право
`member` в §3 и два пункта DoD в §10 — и объявляет «решения по домену не
менялись». v6.15 за добавление права `member` в §3 объявила «ПРАВИТ ИНВАРИАНТ».
Одно и то же действие названо по-разному, значит **самоназвание врезки не может
быть критерием** — состав вычитан из текста каждой из шестнадцати.

## 2. Решение

### 2.1. Указатель §12 — одно предложение на инсайт

Строка = название + одна фраза «когда пригодится» + ссылка. Деталь живёт в
файле, как §12 и обещает. Правило вносится в вводную §12, иначе указатель
отрастёт с первым же новым инсайтом.

**Перед обрезкой** факт про `PR #34` переносится в
`docs/insights/verifying-guards.md`, к описанию четырнадцатого слоя.

Экономия: 18 236 → ~2 880 символов, **~5 120 токенов**.

### 2.2. Преамбула — полными остаются те, что меняли утверждаемое

**Критерий, применённый чтением всех шестнадцати:** врезка остаётся полной,
если она изменила **права ролей (§3) или инварианты §4–§8 и §10** — то есть то,
что документ утверждает и чем побеждает спеку. Строкой — врезка, которая
пополнила §11/§12, поправила процесс §9 или зафиксировала результат проверки,
которую документ сам предписал.

| Полными (8) | Что меняла |
|---|---|
| `v6.16` | текущая ревизия |
| `v6.15` | §3, право `member` на этапный разнос |
| `v6.12` | §10, третий класс денежных поверхностей |
| `v6.10` | §10, вторая ось денежных величин |
| `v6.8` | §10, ось сравнения договоров |
| `v6.7` | §5, §8 сужены; §3, право `admin` на удаление |
| `v6.6` | §3, право `member`; §10, два пункта DoD |
| `v6.3` | §4, уникальность каталожной строки по `sha256` |

Строкой (8): `v6.14`, `v6.13`, `v6.11`, `v6.9`, `v6.5`, `v6.4`, `v6.2`, `v6.1` —
версия, дата, что правила, ссылка. Полный текст → `docs/AGENTS-revisions.md`.

Ссылки вида «ревизия v6.7» остаются рабочими: номер остаётся в преамбуле и
ведёт в `AGENTS-revisions.md`.

Экономия: 19 232 → ~11 230 символов, **~2 670 токенов** — а не ~3 200, как
обещала первая редакция: она сокращала v6.7, v6.6 и v6.3, которые остаются.

### 2.3. Что проверяет скрипт — и чего он не проверяет

`backend/scripts/check_insight_index.py`, read-only: для каждой строки указателя
§12 сверяет **числа и идентификаторы в бэктиках** с текстом связанного инсайта
и падает, если такой факт живёт только в указателе.

**Границу надо назвать прямо: факт обычной прозой скрипт не поймает.** Это
проверка сильного, но узкого свойства, а не доказательство «ничего не
потеряно» — как доля строк в блоках кода была прокси в предыдущей фиче. Полноту
переноса прозы держит чтение на ревью, и DoD ниже сформулирован ровно по
проверяемому свойству, а не по желаемому.

### 2.4. §9.2 получает новый класс документа

`docs/AGENTS-revisions.md` — «полный текст ревизий `AGENTS.md`, не менявших
утверждаемое». Без строки в таблице §9.2 это был бы класс документа, о котором
таксономия молчит, — ровно то, что §9.2 отмечает про `TECH_DEBT.md`: «с
полутора десятками записей не был описан здесь вовсе».

## 3. Отвергнутые альтернативы

1. **Вынести все 16 врезок, оставив только строки.** Экономия ~5 000 токенов,
   но история правки инвариантов уезжает из документа, который объявляет себя их
   источником, — класс ошибки v6.15.
2. **Полными оставить и процессные ревизии** (v6.9, v6.5, v6.2 — §9.2, §9, §5).
   Экономия падает до ~2 250 токенов. Отвергнуто на гейте 1: критерий там —
   «инвариантные целиком, остальные строкой», а процесс виден одной строкой с
   датой и ссылкой.
3. **Вынести §11 и §12 в `docs/reference/` целиком.** Отдельная фича, и
   предложение `2026-09-02-pitfalls-as-mechanisms.md` требует иного порядка:
   сперва разобрать §11 по пунктам, потом выносить.
4. **Оставить в указателе два-три предложения на инсайт.** Экономия вдвое
   меньше, а «сколько предложений достаточно» — резиновый критерий.
5. **Сжать §11.** Раздел целиком — 30 228 символов, и обрезать в нём есть что,
   но это предложение №3, а не эта фича. Прежняя редакция обосновывала отказ
   числом «46 пунктов суммарно 6 301 символ» — это сумма длин **первых строк**
   пунктов, а не пунктов целиком; предмет счёта был назван неверно.

## 4. Что меняется

- `AGENTS.md` — заголовок и врезка **v6.17**; указатель §12 (16 строк);
  преамбула (8 врезок из 16); вводная §12 (правило формата строки); §9.2
  (класс `AGENTS-revisions.md`).
- `docs/AGENTS-revisions.md` — новый файл, полный текст 8 врезок.
- `docs/insights/verifying-guards.md` — принимает атрибуцию `PR #34`.
- `backend/scripts/check_insight_index.py` — новый read-only скрипт.
- **Инварианты §3–§8, §10 не меняются ни одним словом.** v6.17 правит §9.2,
  §12 и форму преамбулы.

## 5. DoD

1. `AGENTS.md` — не больше **105 000 символов** (сейчас 128 052);
2. `check_insight_index.py` зелёный: ни одного ЧИСЛА и ни одного идентификатора
   в бэктиках, живущего только в указателе §12 (границу см. §2.3);
3. все 16 ссылок указателя §12 ведут в существующие файлы;
4. **множество упоминаний `v6.N` минус множество объявленных ревизий пусто** —
   источники и назначения считаются отдельно;
5. `AGENTS.md` объявляет себя v6.17, и §9.2 содержит строку
   `AGENTS-revisions.md`;
6. `just ci` зелёный.

```bash
# 1 — символы, не байты (§0)
python -c "import pathlib;print(len(pathlib.Path('AGENTS.md').read_text(encoding='utf-8')))"

# 2 — проверка указателя
cd backend && uv run python scripts/check_insight_index.py

# 3 — все ссылки указателя существуют
grep -o '(docs/insights/[^)]*\.md)' AGENTS.md | tr -d '()' | sort -u |
  while read f; do test -f "$f" || echo "БИТАЯ: $f"; done

# 4 — ссылки на ревизии разрешаются: упоминания МИНУС объявленные
python - <<'PY'
import pathlib, re
agents = pathlib.Path("AGENTS.md").read_text(encoding="utf-8")
head, body = agents.split("\n## 1. ", 1)
declared = set(re.findall(r"v6\.\d+", head))
revs = pathlib.Path("docs/AGENTS-revisions.md")
if revs.exists():
    declared |= set(re.findall(r"v6\.\d+", revs.read_text(encoding="utf-8")))
refs = set(re.findall(r"v6\.\d+", body))
for p in pathlib.Path("docs").rglob("*.md"):
    if p != revs:
        refs |= set(re.findall(r"v6\.\d+", p.read_text(encoding="utf-8")))
missing = sorted(refs - declared)
print("НЕРАЗРЕШЁННЫЕ:", missing or "нет")
PY
```
