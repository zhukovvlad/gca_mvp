Макет, вторая редакция — гейт 1 фичи 3. Пропорции — из редакции 25.08 (итог первого этапа = 10 000 млн); проценты пересчитаны к предыдущей выбранной колонке. дизайн одобряется в диалоге

Свод по этапам: галочки на решётке, трасса одного участника

Экран отвечает на один вопрос: из чего сложилось изменение цены между этапами торга у одного участника. Не «какая работа подешевела» — это фича 4; не «кто из участников дешевле» — эта поверхность не спроектирована (рамка §5.5), и смешанные трассы оставлены заделом.

Как сюда попадают

Свод — не пункт меню и не вкладка: он строится по выбору, а выбор делается на решётке карточки тендера. По тому же правилу, что «Сравнение договоров» (/compare): вход только из списка галочками.

Тендеры→ Список тендеров
/tenders→ Карточка тендера, решётка
/tenders/{id} + галочки→ Свод по этапам
/tenders/{id}/summary?offers=…

Выбор живёт в URL страницы свода — ссылка воспроизводима. На карточке галочки локальны: перезагрузка сбрасывает (MVP, без сохранения трасс). Колонки «Договор» нет — contracts.awarded_offer_id ещё не существует.

К решётке тендера

Границы макета

  • Один участник на трассу. Смешанные трассы (разные участники в разных колонках) — задел контракта, не этой фичи: подписи «снято/уступка» верны только внутри одного участника.
  • Колонки «Договор» нет до тонкой фичи provenance (awarded_offer_id + «создать договор из раунда»). Место в ответе API зарезервировано элементом kind: 'contract'.
  • Попозиционного раскрытия нет — фича 4. Треугольник доходит до подстатьи.
  • ₽/ед. и ₽/м² не показываются (контракт §10).
  • Печати и выгрузки нет.
  • Сохранённых трасс нет — выбор только в URL.
