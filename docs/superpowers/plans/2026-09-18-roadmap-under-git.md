# План: дорожная карта под гит

**Спека:** `docs/superpowers/specs/2026-09-17-roadmap-under-git-design.md`
**Ветка:** `docs/roadmap-under-git`, от `main` `2135dbe`

## Global Constraints

- **Факт живёт в одном месте** (§9.2). Правило пересмотра карты существует
  ровно в одном экземпляре — в §9.2; в карте остаётся указатель без пересказа.
- **Форма таблицы §9.2 не меняется:** клетка «Где» — одиночный путь в
  бэктиках у всех строк, включая новую. Маршрут для стража живёт в прозе.
- **Продуктовые пункты карты не меняются.** Горизонты А–Г, восемнадцать
  пунктов, строка «Состояние на 09.09.2026» — не тронуты. Служебный раздел
  меняется ровно одним блоком (правило 3).
- **`/tasks` остаётся в `.gitignore` целиком**, негатор не заводится.
- **Страж красен до задачи 5.** План не обещает зелёного `check-agents-index`
  ни на одной задаче раньше той, что заводит ревизию: проверка «каждое
  упоминание версии разрешается» краснеет на спеке и плане, называющих
  `v6.23` (`docs/pitfalls/process.md`).
- **Команду, чей код возврата и есть предмет, запускать без конвейера**
  (`docs/pitfalls/runs.md`).
- **Кириллица:** `read_text(encoding="utf-8")` при чтении, `PYTHONIOENCODING=utf-8`
  при печати из дочернего python. Существующие файлы править точечно, а не
  перезаписью целиком: перезапись переводит файл в LF и делает `git status`
  грязным при пустом `git diff`.
- **Ни один тест не пишет в рабочий репозиторий.** Входы собираются списками
  строк, отсутствие файла подменяется через `monkeypatch` модульной константы
  `ROOT` — образец `backend/tests/unit/test_check_agents_index.py`.
- **В `main` не коммитить; перед пушем — `just ci` целиком** (§9.3): фича
  правит `.py`, освобождение «правки только в `docs/`» к ней не относится.

## Решения плана, которых нет в спеке

1. **Порядок задач.** Перенос → дельта правила 3 → §9.2 → страж → ревизия →
   финал. Он вынужден дважды: `check_18` краснеет, пока §9.2 не несёт маршрут
   (значит задача 3 раньше задачи 4), а тест «зелень на реальном дереве»
   требует существующего файла карты (значит задача 1 раньше задачи 4).
2. **Оракул — коммитимый скрипт** `backend/scripts/verify_roadmap_move.py`, по
   образцу `verify_summary_sheet.py` и `check_drilldown_convergence.py`. Путь к
   источнику он принимает аргументом, а не зашивает: после задачи 6 источника
   не существует, и скрипт обязан сказать это кодом 2 и названной причиной, а
   не позеленеть на пустоте.
3. **Оракул покрыт unit-тестами, а не только снятием.** Его негативные
   утверждения — про потерянную и лишнюю ссылку — ровно те, ради которых он
   заведён; проверять их ad hoc значило бы верить тому, что не прогнано.
4. **Имя константы `ROADMAP_REL`** — по образцу `IMPL_REL`, `SCHEMA_REL`,
   `AXES_REL`.
5. **Тесты `check_18` живут в существующем `test_check_agents_index.py`**, не в
   новом файле: `-k check_agents_index` отбирает по имени модуля, и новые
   тесты попадают в тот же выбор, что старые.
6. **Шапку «Когда читать:» карта уже несёт** — задача 1 её не заводит и не
   правит; `check_18` проверяет, что она ровно одна.
7. **Якорь `#92-таксономия-документов`** — правило слага существующих ссылок на
   подразделы (`docs/reference/screens.md#1-договорыобъекты`): нижний регистр,
   точки и слэши удалены, пробелы в дефисы.
8. **Devlog датируется 2026-09-18** — днём реализации, а не днём спеки.

## Задачи

### Task 1: Перенос карты и оракул переноса

**Files**
- Create: `docs/product-roadmap.md`
- Create: `backend/scripts/verify_roadmap_move.py`
- Test: `backend/tests/unit/test_verify_roadmap_move.py`

**Interfaces**
- Потребляет: `pathlib.Path`, `hashlib`, `re` (стандартная библиотека).
- Производит:

```python
LINK_MOVES: tuple[tuple[str, str], ...]   # десять пар «было → стало», данные скрипта
LINK: re.Pattern[str]                     # markdown-ссылка, группа 1 — ЦЕЛЬ

def strip_link_targets(text: str) -> str
def digest(text: str) -> str              # sha256 текста с LF-нормализацией
def link_targets(text: str) -> list[str]
def verify(source_text: str, moved_text: str, docs_root: Path) -> tuple[bool, list[str]]
def main(argv: list[str]) -> int          # 0 — сошлось, 1 — расхождение, 2 — нет источника
```

**Утверждения**
- у перенесённой карты **ноль** целей, начинающихся с `../docs/`, и десять
  локальных markdown-целей всего;
- список пар «было → стало» совпадает с `LINK_MOVES` поимённо И по кратности:
  `../docs/TECH_DEBT.md` → `TECH_DEBT.md` четырежды,
  `../docs/proposals/2026-08-18-amendments-delta-model.md` →
  `proposals/2026-08-18-amendments-delta-model.md` дважды, и по одному разу для
  четырёх остальных целей;
- каждая из десяти новых целей разрешается в существующий файл относительно
  `docs/`;
- `digest(strip_link_targets(источник))` равен
  `digest(strip_link_targets(перенесённая))` — кроме целей ссылок не изменился
  ни один байт;
- **негативный: изменённый байт ВНЕ целей ссылок краснит оракул**, даже когда
  все десять пар на месте;
- **негативный: потерянная ссылка краснит оракул, хотя остаток сходится** —
  вход, на котором одна сумма без перечня целей молчала бы;
- **негативный: лишняя ссылка краснит оракул при сошедшемся остатке** — вторая
  половина того же: сходимость не доказывает разбиения, и обе стороны
  предъявляются раздельно;
- **негативный: замена не по карте** (`../docs/TECH_DEBT.md` → `../TECH_DEBT.md`)
  краснит оракул: пары нет в `LINK_MOVES`;
- **негативный: новая цель не разрешается** в существующий файл — краснит,
  даже если пара из `LINK_MOVES`;
- **отсутствие файла-источника даёт код 2 и названную причину**, а не молчаливый
  ноль: после задачи 6 скрипт неприменим по построению, и молчать об этом он не
  вправе;
- карта переносится копированием БАЙТОВ; перенесённый файл отличается от
  источника только целями ссылок — это и есть утверждение, которое оракул
  доказывает;
- новый файл отслеживается (`git ls-files docs/product-roadmap.md` печатает
  путь), а `/tasks` остаётся игнорируемым целиком: `git check-ignore -q tasks`
  возвращает 0 и `git ls-files tasks/` пуст — негатор не заведён.

**Имена**
- Заводятся этой задачей: `LINK_MOVES`, `strip_link_targets`, `digest`,
  `link_targets`, `verify`, `main`, `docs/product-roadmap.md`.
- Существуют, проверено `grep`-ом: `backend/scripts/verify_summary_sheet.py`
  (образец формы скрипта), `backend/tests/unit/` (каталог unit-тестов).

**Проверка**
- `just test-unit-k verify_roadmap_move` — зелёная. Выбор ДО задачи: **0**
  (модуля нет). ПОСЛЕ: **7** — по одному тесту на зелень и на шесть негативных
  утверждений выше.
- `PYTHONIOENCODING=utf-8 python backend/scripts/verify_roadmap_move.py <путь к
  источнику> docs/product-roadmap.md` — код **0**, без конвейера.
- `just check-agents-index` — **16 из 17**, код 1. Зелёного стража эта задача
  не обещает: красна проверка 5 и только на спеке и плане.
