# Случаи с данными

Разобранные случаи, когда экран показал неожиданное из-за **данных**, а не
кода: не тот договор в истории, строка не в той семье, файл не той версии.
Класс назван в [`AGENTS.md`](../../AGENTS.md) §9.2; его граница и порядок
пополнения — здесь, с той же силой.

**Случай хранит путь диагностики, а не решение**: что увидели, где искали, что
нашли, что сделали руками. Дефект кода, найденный по дороге, — запись
[`TECH_DEBT.md`](../TECH_DEBT.md), недостающая функция — пункт [дорожной
карты](../product-roadmap.md), общее правило, выведенное из нескольких
случаев, — грабля (`AGENTS.md` §11) или инсайт (§12); случай на них ссылается
и не пересказывает. Случай описывает данные на свою дату и после записи не
поддерживается, как смерженная спека.

## Когда заводить случай

**Случай заводит тот, кто разбирал, — тем же днём**: как только ручной разбор
данных закончен (причина найдена, сделано или решено «не трогать»), а не
«после следующей фичи». Отдельным PR только с документацией; если разбор шёл
внутри фичи — в её ветке, рядом с devlog. Повод — разбор, на который ушло
больше одного шага: если причину видно с первого взгляда, случай не нужен.

## С чего начинать разбор строки «Против нашей цены»

1. **Ответ строки.** Панель строки берёт его с
   `GET /api/v1/tenders/{тендер}/rounds/{этап}/our-price/offers/{оффер}/lines/{позиция}`
   — открыть панель и посмотреть ответ во вкладке Network браузера, либо
   открыть адрес напрямую в той же вкладке, где выполнен вход. Поля, которые
   отвечают на «почему так»: `state`, `no_history_reason`, `family`,
   `variant_label`, `unit`, `zone`, `work_rung` (ступень и что отпущено),
   `analogs_count`, `unit_mismatch` (`all_outliers` и отношения по аналогам).
2. **Аналоги и их договоры.** У каждого аналога в ответе — `contract_id`,
   номер, объект, подрядчик, цена `net` и `outlier_ratio`. Подозрительный
   номер или цена в рубли — первым делом открыть этот договор.
3. **История — только сметы договоров.** Строки КП историей не бывают; чужая
   цена в аналогах всегда пришла из какого-то договора.
4. **Каталог.** Семья и вариант строки — на экране каталога. Если аналогов нет,
   проверить, нет ли той же работы в семье-близнеце с другой единицей и не
   отпущен ли нужный параметр.
5. **Файл.** Если подозрение на сами числа строки — сверить `sha256` файла на
   диске с `import_jobs.file_sha256` (случай 2026-08-23).

Запросы к базе в случаях — только чтение. Строки подключения, пароли и ключи
сюда не пишутся.

## Как написать случай

Файл `ДАТА-тема.md`, где дата — день разбора. Разделы: **Симптом** (что
увидел пользователь, на каком экране, идентификаторы тендера, оффера, строки);
**Как нашли** (поля ответа, запросы, пробы — по шагам); **Причина**; **Что
сделали**; **Что осталось** (ссылки на долг, карту, грабли). Строку — в таблицу
выше.
