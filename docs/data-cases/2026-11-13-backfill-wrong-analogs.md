# 2026-11-13 · Засыпка пазух: аналогами пришли засыпки под рампой

## Симптом

КП C5/MIND (тендер 7, оффер 76), строка «Обратная засыпка пазух котлована
песком» (позиция 223520, контекст 7111). В аналогах на экране «Против нашей
цены» — «Засыпка под рампой песком» из статьи «Отделочные работы»: другая
работа и другая цена.

## Как нашли

1. Ответ строки: семья 131 «Обратная засыпка песком», вариант «не уточнено».
2. Схема семьи в каталоге: семья делилась только по параметру «Уплотнение».
   Строка КП уплотнения не называет → вариант «не уточнено», а туда же попали
   засыпки под рампами. Настоящие засыпки пазух (Jois, VEER UB2/UB9, МИРА,
   Тушино; класс 3) лежали в варианте «послойное уплотнение».
3. «Можно отпустить» у «Уплотнения» не размечено, поэтому отпущенная ступень до
   засыпок пазух не доходила. Статья в подборе аналогов не участвует (спека
   лестницы аналогов §2.8) — «Отделочные работы» у аналога ничего не
   отсекают.

## Причина

Схема семьи не различала место работы: пазухи, рампа и приямки жили в одной
семье без параметра, который их разводит.

## Что сделали

Пользователь, «Править схему» семьи 131:

- главный параметр «Место» — пазухи котлована / под рампой / приямки, только
  из списка;
- «Уплотнение» — «можно отпустить»;
- значение «пазухи перепада высот ФП» слито в «пазухи котлована».

Ожидаемо после пересчёта — ступень 2 «без Уплотнения», пять аналогов класса 3.

По дороге нашёлся дефект кода: модель дописала значение параметра, и девять
уже полученных верных ответов по соседним контекстам отменились без
перезапроса — схему пришлось сохранять повторно. Починено в PR #77.

## Что осталось

- «Не аналог» в панели строки с предложением различающего параметра моделью —
  в очереди после упрощения каталога; этот случай — пример для дизайна;
- объяснение в панели: по каким значениям совпал аналог, пометка «аналог из
  другой статьи».

Признак для следующего раза: аналог из чужой статьи и «не уточнено» у строки
КП — смотреть схему семьи: чего в ней не хватает, чтобы развести работы.
