## 1. Цель

Веб-приложение для небольшой команды (2–5 человек), которое:
- Загружает PDF-файлы УПД (универсальных передаточных документов) от поставщиков
- Автоматически извлекает данные (поставщик, материал, цена, объём, дата)
- Отслеживает среднюю цену материалов в разрезе месяцев/кварталов
- Показывает дашборд с графиками динамики цен и сравнением поставщиков
- Позволяет выгружать отчёты в Excel для обоснования удорожания

Основные типы материалов: бетон (различных марок) и арматура.

## 4. База данных

```sql
-- Поставщики
suppliers (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    inn TEXT,
    created_at DATETIME
)

-- Справочник материалов
materials (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,        -- "Бетон М300 В22.5"
    unit TEXT NOT NULL,        -- "м3", "т", "шт"
    category TEXT              -- "Бетон", "Арматура"
)

-- УПД — заголовок документа
invoices (
    id INTEGER PRIMARY KEY,
    number TEXT NOT NULL,      -- "АБ000009026"
    date DATE NOT NULL,        -- "2025-06-01" (ISO 8601)
    supplier_id INTEGER REFERENCES suppliers(id),
    pdf_path TEXT,             -- путь к исходному файлу
    parse_method TEXT,         -- "claude_api" | "manual"
    ai_confidence REAL,        -- 0.0–1.0
    created_at DATETIME
)

-- Позиции УПД
invoice_items (
    id INTEGER PRIMARY KEY,
    invoice_id INTEGER REFERENCES invoices(id),
    material_id INTEGER REFERENCES materials(id),
    quantity REAL NOT NULL,
    unit_price REAL NOT NULL,
    amount REAL NOT NULL,
    nds_rate REAL DEFAULT 20.0
)

-- Кэш средних цен (пересчитывается при добавлении УПД)
price_stats (
    material_id INTEGER REFERENCES materials(id),
    year INTEGER,
    month INTEGER,
    avg_price REAL,            -- средневзвешенная: Σ(цена×кол-во)/Σ(кол-во)
    min_price REAL,
    max_price REAL,
    total_qty REAL,
    doc_count INTEGER,
    PRIMARY KEY (material_id, year, month)
)
```

**Расчёт средней цены:** средневзвешенная `Σ(цена × количество) / Σ(количество)`.

## 5. PDF-парсер (Claude API)

```
1. pdf2image конвертирует страницы PDF → изображения
2. Изображения + промпт отправляются в Claude API (vision)
3. Промпт: извлечь из УПД номер, дату, поставщика, строки таблицы
          (наименование, ед.изм., кол-во, цена, сумма) → JSON
4. Уверенность оценивается по полноте ответа (0–100%)
5. Если Claude не смог → статус "Ошибка", документ на ручную проверку
```

**Модель по умолчанию:** `claude-sonnet-4-6`
**Настраивается** через страницу Settings: `claude-haiku-4-5-20251001` / `claude-sonnet-4-6` / `claude-opus-4-6`
**API-ключ** хранится в `.env`, вводится через интерфейс Settings.

## 6. Экраны приложения

### 6.1 Дашборд (главная)
- Горизонтальная навигация сверху
- Под навигацией: фильтры — материал, поставщик, период (месяц/квартал/год)
- KPI-карточки: средняя цена, изменение к предыдущему периоду, кол-во поставщиков, кол-во УПД
- График динамики средней цены (Recharts LineChart) — во всю ширину
- Под графиком: таблица по месяцам (месяц, ср. цена, мин, макс, объём, сумма, изм. %)

### 6.2 Загрузка УПД
- Drag-and-drop зона (или кнопка выбора файлов/папки)
- Переключатель **"Доверять ИИ без проверки"** (по умолчанию включён)
- Ползунок порога уверенности (по умолчанию 70%)
- Очередь файлов: зелёный (авто-сохранено) / жёлтый (на проверку) / серый (в очереди) / красный (ошибка)
- Счётчики: сохранено авто / требует проверки / в очереди
- Кнопка "Проверить помеченные (N)"

### 6.3 Проверка УПД
- PDF-просмотрщик слева (листание страниц)
- Форма справа: поставщик, дата, строки позиций (наименование, ед., кол-во, цена)
- Кнопки: "Сохранить" / "Пропустить" / "Следующий"

### 6.4 Поставщики
- Список поставщиков с кол-вом УПД и датой последней поставки
- Редактирование названия и ИНН

### 6.5 Материалы
- Справочник материалов с категориями
- Объединение дублей (например "Бетон М300" и "Бетон М300 В22.5" → одна запись)

### 6.6 Отчёты
- Выбор периода и материала
- Генерация Excel-файла: таблица средних цен по месяцам + сравнение поставщиков

### 6.7 Настройки
- API-ключ Anthropic (поле ввода, сохраняется в `.env`)
- Выбор модели Claude: Haiku / Sonnet / Opus
- Порог уверенности по умолчанию

## 7. Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| PDF не читается (битый файл) | Статус "Ошибка", ручная проверка |
| Материал не распознан | Уверенность 0%, всегда на проверку |
| Дубликат УПД (номер + дата) | Предупреждение перед сохранением |
| Claude API недоступен / нет ключа | Загрузка блокируется, уведомление в Settings |
| Поставщик не найден в справочнике | Создаётся новый, помечается для проверки |
